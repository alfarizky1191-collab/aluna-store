# Aluna Store

Website katalog Aluna Store dengan dua etalase:

- `/food/` untuk Aluna Eats
- `/apps/` untuk Premium Apps
- `/admin/` untuk satu admin mengelola produk

Produk, harga, gambar, varian, dan pilihan disimpan di Supabase. Checkout tetap diteruskan ke WhatsApp.

Panduan pemasangan: [SETUP.md](SETUP.md).
